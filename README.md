# LLM Copypaster

LLM Copypaster — это VS Code extension для разработчиков, которым нужен предсказуемый и управляемый workflow при работе с LLM.  
Он собирает контекст из файлов в IDE, автоматически дополняет его project-specific инструкциями из конфигурации, помогает отправить результат в любой LLM-интерфейс и затем применить ответ обратно в проект.

Расширение не привязано к конкретному провайдеру или AI-обёртке: его можно использовать как с raw API, так и с Cursor, Claude Code, Copilot, ChatGPT UI и другими инструментами. Проще говоря, это способ работать с LLM через понятный процесс, а не через надежду, что «умная интеграция» в этот раз всё поняла правильно.

## Why use it

Многие AI-инструменты хорошо автоматизируют взаимодействие с моделью, но при этом скрывают важные детали: какой контекст был передан, какие правила были добавлены и почему ответ выглядит именно так.

LLM Copypaster делает акцент на другом:

- помогает быстро собрать нужный контекст из IDE
- автоматически добавляет инструкции проекта к собранному prompt сугубо согласно пользовательской конфигурации
- позволяет использовать единый подход и набор инструкций в разных LLM-интерфейсах
- возвращает разработчику контроль над тем, что именно уходит в модель и что именно приходит обратно

Это особенно полезно там, где важны повторяемость, прозрачность и project-specific правила работы, а не только эффектная кнопка “Ask AI”.

## Core capabilities

### Context collection from IDE

Расширение позволяет быстро собрать контекст из файлов и папок прямо из VS Code через команды в editor и explorer menu.  
Поддерживаются базовые сценарии: копирование текущего файла, файлов текущей tab group, выбранных файлов и обратное применение clipboard в проект. Остальные команды — это близкие вариации тех же рабочих сценариев.

### Project instructions as part of the flow

Ключевая особенность расширения — не просто копирование файлов в clipboard, а автоматическое добавление инструкций по правилам проекта.

Именно это делает workflow действительно полезным:

- модель получает не только код, но и нужные правила работы
- для каждого проекта можно использовать свой набор инструкций
- один и тот же extension остаётся применим в разных командах и репозиториях

### LLM → IDE flow

Расширение умеет взять ответ LLM из clipboard и применить его обратно в файлы проекта через команду `Paste Clipboard to Files`.

Итоговый цикл выглядит так:

1. Собрать контекст из IDE
2. Автоматически добавить инструкции проекта
3. Отправить результат в любой LLM
4. Получить ответ
5. Применить изменения обратно в проект

Этот подход хорошо подходит для сценариев, где важны скорость, прозрачность и контроль над форматом обмена.

## Who it is for

LLM Copypaster особенно полезен, если вы:

- работаете с raw API и хотите сами контролировать prompt
- используете AI-обёртки, но хотите минимизировать зависимость от их скрытой логики
- ведёте несколько проектов с разными требованиями к похожим инструкциям
- хотите единый и понятный workflow для работы с LLM через VS Code

## Main commands

Для знакомства с расширением достаточно нескольких основных команд:

- Editor context menu: `Copy This File` / `Copy Tab Group Files`
- Explorer: `Copy Selected File(s)`
- Ctrl+Alt+V: `Paste Clipboard to Files`
